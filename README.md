# PayFlow – Payroll Automation

A single-page payroll app: employees, attendance, leave, payroll, payslips, backup and CSV export.

## Deploy
1. Upload `index.html`, `vercel.json` and `README.md` to a GitHub repository.
2. In Vercel, choose **Add New → Project**, import the repository, and click **Deploy**. No build settings are needed.

## Default login
- Username: `admin`
- Password: `admin123`

Change the password in **Settings → Change password** after your first sign in.

## Notes
- Data and logins are stored in each user's browser (localStorage), not on a server.
- Use **Settings → Download backup** to keep a copy of your data.
